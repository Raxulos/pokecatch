# Pokécatch

Dein Pokémon-Sammeltracker im Stil der PC-Boxen – von Rot/Blau bis Legenden: Z-A, inklusive Pokémon HOME.

- 30 Plätze pro Box oder alle Boxen in einer Übersicht
- Normal- und Shiny-Fangstatus getrennt verfolgen
- Pokémon suchen und Entwicklungen ansehen
- 46 Boxhintergründe zur Auswahl
- Für Desktop und Handy

## Starten

`Pokécatch.html` im Browser öffnen und eine Reise starten. Deine Fortschritte werden lokal im jeweiligen Browser gespeichert. Über Export und Import kannst du Backups sichern und zwischen Geräten übertragen.

## Hinweise

Pokémon-Bilder und Entwicklungsdaten benötigen eine Internetverbindung. Eine automatische Synchronisierung zwischen Geräten gibt es derzeit nicht.
